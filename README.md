# Rukmani Motors Arena — Fuel Suitability Tool

Mobile-first Petrol vs S-CNG customer counselling calculator inspired by the supplied NEXA-C4 reference.

## Included
- Rukmani Motors Arena branding
- Arena CNG model selector
- Daily running, petrol/CNG price and mileage inputs
- Petrol vs CNG cost/km
- Personal/Taxi, driving preference, queue tolerance, refuelling comfort and CNG station access
- 0–100 suitability score and recommendation
- CNG price-premium + estimated finance interest
- Break-even kilometres and recovery period
- Editable model defaults in `index.html`

## Deploy on GitHub Pages
1. Create a GitHub repository.
2. Upload `index.html`.
3. Settings → Pages → Deploy from branch → select `main` / root.
4. Share the generated Pages URL.

## Important
The model premiums are editable starting values, not a substitute for the current Rukmani Motors quotation. Update `premium` values and fuel prices whenever your dealership price list changes.
